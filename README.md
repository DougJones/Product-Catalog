# ProductsClient

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.19.

## Development server

To start a local development server, run:
1) Node packages will have to be installed be installed prior to running, run the following command: npm install while in the Products.Client folder.
2) Navigate to Products.Server folder and run the following command to start the backend server: dotnet run
	The backend server will start and listen on the default port (usually `http://localhost:5000`).
	The backend server will handle API requests and serve data to the Angular frontend.
	The frontend Angular application will be started and make HTTP requests to the backend server to fetch and manipulate data.
	Open your browser and navigate to `http://localhost:54015/` to access the Angular application.



##Usage
A list of products will be displayed on the main page. You can perform the following actions:
	- View product details by clicking on a product.
	- Search for a product using the text search bar by starting to type a product name.
	- Search for products by unit of measure using the dropdown menu.
	- In the details page, you can click 'Add to List' to email product details to a contact.
